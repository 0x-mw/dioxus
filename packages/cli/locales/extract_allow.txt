# extract.py scan --unclassified 재현율 게이트 허용목록 (커밋되는 파일)
#
# 이 목록은 "화면 메시지가 아닌 것"만 담는다: HTML/JS/CSS/XML 템플릿, 셸·cargo 인자, 경로,
# 생성 파일 내용, 텔레메트리·내부 식별자, debug 전용 문자열, 기계 출력. 사람에게 보이는 메시지는
# 여기에 넣지 말고 extract.py 의 추출 규칙을 고친다.
#
# 항목 형식 (한 줄에 하나, 맨 끝 ` ## 범주: 사유` 가 필수):
#   파일.rs                      파일 전체 (쓰지 않는다 — 새 메시지까지 가리므로)
#   re:정규식                    어느 파일이든 문자열(re.search)에 맞으면
#   파일.rs:re:정규식            그 파일의 문자열에 맞으면
#   파일.rs:리터럴 앞부분        그 파일의 문자열이 (앞 공백을 뗀 뒤) 이 앞부분으로 시작하면
# 사유의 ':' 앞이 범주 이름이며 scan --unclassified 의 요약에 범주별 개수로 나온다.
# 위에서부터 처음 맞는 항목만 적중으로 센다(그래서 구체적인 항목을 일반 정규식보다 앞에 둔다).
# 후보 제거(scan --json·skeleton 에서 빠짐)는 `파일.rs:리터럴 앞부분` 항목만 한다. re:·파일 단위 항목은
# 미분류 게이트에만 적용되어, 확정된 사람용 규칙으로 추출된 후보는 지우지 않는다.
# scan --unclassified 는 후보에서 뺀 항목을 stderr 에 모두 나열한다.
